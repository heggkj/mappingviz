Field guide

How to read the project dataset

One row per project
Each record is identified by a stable Project ID beginning with bdph_.
Multi-value fields
Project types, topics, eras, organization types, contributor roles, leadership classifications, and funding resources are separated with semicolons.
Dates and recency
Raw project-start and update values are retained alongside cleaned years, decades, last-updated categories, and status fields. Unreadable years remain blank.
Geographic fields
Location text, country, city, state or region, latitude, longitude, and coordinate-sharing indicators support the geographic visualization.
Unknown values
Unknown or unparsed values remain explicit rather than being inferred or filled in.
Privacy
The public project CSV excludes contact-email fields. It contains the public catalog and derived classification fields used in the visualizations.
